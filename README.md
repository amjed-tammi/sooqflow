
# SooqFlow

A full-stack e-commerce and inventory management platform.

## Business Problem

Small retailers need a way to manage products,
inventory, and customer orders in one system.

## Users

- Customers: browse products and place demo orders.
- Store Staff: manage products, inventory, and orders.

## Planned Features

- Product Catalog
- Product Search and Filters
- Shopping Cart
- Demo Checkout
- Order Management
- Inventory Management
- Admin Dashboard

## Tech Stack

The project will evolve gradually:

1. HTML, CSS, JavaScript
2. Python and FastAPI
3. PostgreSQL
4. React and TypeScript
5. Testing, CI/CD, and Deployment

## Project Status

Phase 0: Initial setup.

This is a portfolio and learning project.
No real payments will be processed.
